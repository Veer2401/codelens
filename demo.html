🚀 Live Complexity Visualizer

See code complexity in real-time with beautiful visualizations

📊 How It Works

This Chrome extension automatically analyzes JavaScript/TypeScript code on supported platforms and provides:

  • Real-time complexity analysis using Esprima AST parsing
  • Inline highlights with color-coded backgrounds
  • Floating widget showing overall metrics
  • Detailed popup with charts and function breakdowns

🔍 Code Analysis Example

Here's a sample JavaScript function that the extension would analyze:

function calculateUserScore(user, transactions, preferences) { let score = 0; // Base score calculation if (user.isVerified) { score += 100; } // Transaction analysis for (let i = 0; i < transactions.length; i++) { const transaction = transactions[i]; if (transaction.amount > 1000) { score += 50; } else if (transaction.amount > 500) { score += 25; } else if (transaction.amount > 100) { score += 10; } if (transaction.type === 'credit') { score += 20; } else if (transaction.type === 'debit') { score -= 10; } } // Preference matching if (preferences && preferences.length > 0) { for (let j = 0; j < preferences.length; j++) { const preference = preferences[j]; if (preference.category === 'high_value') { score += 30; } else if (preference.category === 'frequent') { score += 15; } } } // Final adjustments if (score > 500) { score = Math.min(score, 1000); } else if (score < 0) { score = 0; } return score; }

Complexity Analysis Results:

  • Function: calculateUserScore
  • Complexity Score: 15 (High)
  • Control Flow Statements: 8 if/else statements, 2 for loops
  • Recommendation: Consider breaking into smaller functions

🎨 Visual Features

🟢 Low Complexity (1-5)

Excellent code quality. Functions are simple and easy to understand.

🟡 Medium Complexity (6-10)

Good code quality. Consider minor improvements for better maintainability.

🔴 High Complexity (11-15)

Fair code quality. Functions need refactoring to reduce complexity.

🟤 Extreme Complexity (16+)

Poor code quality. Major refactoring required to improve maintainability.
